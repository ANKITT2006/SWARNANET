# SWARNANET 2.0

SwarnaNet is an institutional bullion derivatives intelligence platform and analytics terminal.

## Repository Structure

- **`SwarnaNet/`**: Core bullion derivatives analytics engine, scripts, backend services, and intelligence dashboard.
- **`UI-UX template and research/`**: Modern Next.js UI/UX frontend prototype, research templates, and visualization components.
